# Contributing

Provide the source revision, Windows build/UBR, toolchain, endpoint/provider, input fixture, scheduling configuration and exact failure when reporting an issue. Use self-generated fixtures; do not upload game audio, process dumps, proprietary SDKs, credentials or unrelated system data.

Keep changes to capture, transport, metadata and rendering independently reviewable. Preserve version/protection checks, bounded queue ownership, shutdown ordering and the three-thread MMCSS default. New build support requires evidence about the relevant binary and layout rather than deleting a check.

Contributions intentionally submitted for inclusion are offered under the project's Apache-2.0 terms unless explicitly stated otherwise, subject to upstream terms for third-party-derived files. State the source and license of any third-party material.
