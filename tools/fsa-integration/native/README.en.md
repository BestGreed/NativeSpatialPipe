# Native source

[简体中文](README.md) | English

Pure C11 / Win32 implementation. Build with `build.ps1`; package with `release.ps1` in the repository root.

Copy `final-spatial-audio.example.ini` to `final-spatial-audio.ini` to configure local rules and the optional `Language=auto/zh/en` setting. Personal rules, profiles, logs and build outputs are ignored by version control. Restart after changing the language.
