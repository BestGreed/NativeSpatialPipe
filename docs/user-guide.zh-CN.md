# 用户手册

[English user guide](user-guide.md)

NSP 将空间音频和普通 PCM 送往选定的扬声器输出。Final Spatial Audio（FSA）常驻 Windows 任务栏通知区域，浏览器前端提供配置、状态和可视化。FSA 根据 Windows 显示语言选择中文或英文；Web 宿主采用 FSA 启动时选定的语言，默认回退到英文。

## 安装

运行 NSP Setup，生成初始配置和程序路径。

1. 核对 Windows 默认播放端点。需要更换时，打开声音设置，选择目标端点，回到安装器点击 Refresh／刷新。
2. 选择空间模式、声道布局和输出路径。
3. 按输出路径完成设备设置：

| 输出路径 | 设置 |
| --- | --- |
| ASIO | 安装声卡厂商的驱动，选择驱动并将声道名称映射到物理输出。界面通道号从 1 开始。 |
| AoIP | 选择发送网卡，使用 PTP 自动发现或固定主时钟。在网络控制器中将接收设备订阅到 NSP 的相应通道。 |
| LSAC（实验性） | 为 7.1.4 → 2.0 输出选择独立的立体声播放端点和匹配滤波文件。laptop 滤波器用于对应的笔记本扬声器方案。 |

4. 混合播放通常保留普通 PCM 捕获；空间流专用输入可关闭此项。
5. 从开始菜单或桌面快捷方式打开 Final Spatial Audio (NSp)，接受 Windows 权限提示。

安装结束页提供可选的 ASIO 声道试听。先降低实际音量，再开始试听，按声道名称检查扬声器。AoIP 在网络控制器中完成接收端订阅；LSAC 选择与实际播放设备匹配的滤波文件。

## 托盘和浏览器

在任务栏通知区域找到 FSA，图标收起时展开“显示隐藏的图标”。右键图标打开菜单；快速连续左键点击三次，启动 Web 宿主并打开浏览器，点击间隔遵循 Windows 双击时间设置。

- 首页：`http://127.0.0.1:8767/`。
- 配置：`http://127.0.0.1:8767/configuration.html`。
- 现场数据：`http://127.0.0.1:8767/#live`。

先通过托盘启动宿主，再使用地址或书签。FSA 控制音频会话，浏览器用于配置和可视化。

## 启动和停止

1. 在托盘菜单选择 NSp，等待启动完成。
2. 使用选定的 Windows 捕获端点播放声音。
3. 打开“配置”，核对当前状态、端点和配置。
4. 选择“数据源 → 连接”，使用 `ws://127.0.0.1:8766/v1/telemetry`，或打开现场数据地址，观察输入、输出和声道电平。
5. 在目标扬声器或接收设备试听，检查位置和音量。

选择“NSp／停止 NSp”停止音频。选择“退出”关闭 FSA 并完成清理。暂停、重置相机和数据源操作用于画面及显示数据。

“高级 → 开机自启”让 FSA 随 Windows 登录启动，登录后通过 NSp 开始会话。“自动切换”按应用规则工作，可通过意图捕获、编辑规则和重新加载规则维护。Stereo、5.1、7.1、Sonic、Atmos 和 DTS 菜单项用于选择 Windows 端点模式。“高级 → 查看日志”打开 FSA 日志。

## 播放配置

打开“配置 → 播放与公共 DSP”，保留已准备的模块路径，按实际设备和接线调整。

| 配置节点 | 设置 |
| --- | --- |
| 渲染器／输出 | 驱动或端点、布局和采样率。初次使用保留 ROAR OLR 预设。 |
| ASIO 路由 | 按声道名称匹配物理输出，从 1 开始，并核对路由预览。 |
| AoIP | 发送网卡 IPv4、设备名、PTP 主时钟和接收端订阅。初次保留生成的设备标识、发送延迟和缓冲。 |
| LSAC | 物理播放端点、匹配滤波文件和共享／独占模式。初次使用共享模式及 7.1.4 → 立体声输出。 |
| PCM | 空间流与普通 PCM 统一输入跟随 FSA 会话端点。 |
| Joint 上混 | 启用普通 PCM 捕获、统一输入和 ROAR OLR 7.1.4，保留模型及库路径。关闭上混可降低 CPU 占用。 |
| Media Foundation | 启用 Apple Music／电影和电视适配，再打开相应播放器。 |
| 公共 DSP | 主音量、线性 Trim、延迟和 limiter。Trim 为 1 时保持原值；48 kHz 下 48 帧为 1 ms。Bypass 跳过这一组处理。 |
| 诊断 | 排查时启用录制、统计或快照，并留意磁盘空间。 |
| 后端默认配置 | 设置启动默认值，再重启对应后端服务。 |

点击“校验并保存”，然后按修改内容应用：

1. 普通播放和 DSP：停止并重新启动 NSp。
2. 输出后端或 AoIP 参数：退出并重新打开 FSA，再启动 NSp。
3. 后端启动默认值：重启对应后端服务。

遇到文件修订冲突时，重新读取配置、合并编辑并保存。高级 JSON 先应用到表单，再保存。启停、端点模式和急停通过 FSA 操作。

## 恢复和更新

播放静音时检查应用输出、捕获端点、现场电平、音量和物理路由。AoIP 还需检查时钟同步和接收端订阅。浏览器连接失败时确认 FSA 在运行，再三连击托盘图标。上混 CPU 占用较高时关闭上混，保存并重启会话。

遇到未结束会话或故障锁，选择“NSp／停止 NSp”请求停止和核验，等待清理后再次启动。在线状态检查也会处理可恢复的旧会话。“高级 → 急停 NSp”执行收尾和恢复检查。Windows 更新后，可更新捕获布局或导入匹配布局。

升级前退出 FSA。安装器保留已有设置；勾选 Replace my existing playback settings with these choices 可应用本次选择并备份旧配置。卸载保留用户设置。

## 问题反馈

配置和报告位于 `%LOCALAPPDATA%/NativeSpatialPipe`，配置页显示实际配置路径。“高级 → 查看日志”打开 FSA 日志。

反馈时提供版本、Windows 版本、输出路径、捕获端点、空间模式、操作时间、状态码和电平变化。网络或推理问题可附驱动信息或推理选择记录。`AGENTS.md` 为诊断 agent 提供版本和日志位置。
