# Additional endpoint enumeration migrated to native MinHook

2026-10-24, replace the Frida injection path of `tools/pipeline-init/manager.py`, and remove the product with `agent.js`. No changes to the seven modes, two additional sets of enumeration switches, FSA active memory tags, or HT/EDID explicit entries; no modifications to PCM capture, rendering, DSP, or ASIO.

## Realize boundaries

- `Enum-Hook.c/.h`: C DLL, after the original three functions of AudioSrv return successfully, only the results of the specified endpoint and specified format are modified; the field offset and validity period are consistent with the original script. The original HRESULT, untargeted results, and LastError are retained.
- `native_enum.py`: Python control adapter, call DLL export through `nsp_enum_control.exe`; Frida is not imported and scripts are not loaded.
- `Native-Hook-Control.c`: Reuse a native LoadLibrary/remote export call source code with PCM capture to build the enumeration controller with `NSP_ENUMERATION_CONTROL`; process target verification is separated, and the enumeration only accepts System32 AudioSrv in System32 svchost or explicit test host.
- MinHook is fixed to `c3fcafdc10146beb5919319d0683e44e3c30d537`. Both Python and the controller check the original AudioSrv SHA-256; the DLL then checks the three function prologues. The system explicitly rejects update hashes that do not match and does not scan to guess the new address.
- Native watchdog monitors process handles and five-second leases. When stopping, close the result modification entry, disable three Hooks, wait for the result modification in progress, and check the original 32 bytes. Keep disabled trampoline and fixed small DLLs to prevent threads that have entered the original function from returning to released code.
- Auditing after an abnormal exit only uses ReadProcessMemory; the service PID creation time is still checked and old bytes are not written back to any new process. The three raw byte evidence generated by the old script can also be audited read-only without the need to restore Frida.

There are still two types of interception locations: AudioSrv enumeration and audiodg capture. These are two responsibilities and target processes, not two sets of injected runtimes. Both are now unified as native controllers and MinHook, ready supervision remains in the control plane and does not enter the per-packet audio chain.

## Build and verify

```powershell
powershell -File tools/pipeline-init/Build-EnumHook.ps1 -TestFixtures
python -m unittest discover -s tools/pipeline-init -p 'test_*.py' -v
```

A total of 54 isolation tests passed (including 7 new native Hook tests), covering three real MinHook intercepted field results, format/endpoint range, original function failure, short array, repeated start and stop, and byte-by-byte recovery, as well as cross-process control, lease expiration, and automatic recovery after the supervision process is terminated. EDID and existing memory tag tests still pass.

Explicit real machine entry `Validate-NativeEnumeration.py --output <JSON>` requires administrator rights and denies existing enumeration residents. Only enable two sets of enumerations, query four additional modes, cancel and recheck; do not switch modes, do not start capture, do not write EDID, and do not restart the audio service.

The actual machine result of this round: `build/native-enumeration-20261024/live.json`, passed. The native Hook ready on AudioSrv PID 4184, the shared memory tag is alive, and all four query modes are supported; all three original bytes are restored after normal stop, and the independent ReadProcessMemory audit reconfirms the recovery in three places. The active/default before and after are DTS:X HT, supporting consistent readings. The test ends with no active enumerations resident. This device already supports four modes before testing, so this actual machine verification cannot be used as a negative and positive control for "not supported → supported"; the modification of the limited field is verified by the native isolation fixture.
