# Web 配置与状态 Host

2026-10-23。按用户确认实现：本轮不加 Web → FSA 控制。独立 Web API Host 随 FSA 启动，提供状态读取、现有 JSON 配置读取与保存，复用原 Web 前端增加配置页。FSA 仍拥有启停、空间模式、Hook、端点互验、HT Support 与急停。

## 模块与生命周期

- `nsp-scheduler.exe web-host` 是独立进程、独立 Zig 模块；不创建音频 host、PCM 队列或 ASIO 设备。复用可执行文件不代表与音频线程共进程。
- FSA 启动时启动 Web Host；FSA 以管理员运行时，从 Explorer 用户令牌创建普通权限 Host，不把管理员令牌交给 HTTP 服务。启动失败仅记录日志，不影响 FSA 管理与声音。
- 监听地址固定为 `127.0.0.1:8767`。FSA 启动不自动弹浏览器；托盘图标连续三次左键释放，在系统双击间隔内逐次完成，用默认浏览器打开首页。单击/双击等到判定窗口结束后显示原菜单，右键即时显示菜单并清空点击计数。
- Web Host 绑定启动它的 FSA 进程句柄，FSA 退出后自行退出；关闭浏览器不停止 FSA 或声音。Host 意外退出后，下次三击会重新尝试启动。
- FSA 工作线程把已有状态写入固定、无指针的只读共享内存观察结构；没有新增端点查询线程。Web 请求读取快照并查询已经存在的后端；后端不在线则返回离线，不调用 `ensure`。工作线程阻塞时快照会显示过期。
- 原 `app.js`、绘图、数据源、WebSocket 遥测和回放逻辑保持不变；首页仅增加配置链接和对应链接样式。原遥测服务仍按音频会话生命周期运行，不与配置 Host 合并。

## 配置合同

| 配置 ID | 文件 | 校验与生效 |
|---|---|---|
| `playback` | 10/24 起默认 `%LOCALAPPDATA%/NativeSpatialPipe/playback.json`；自定义 `PlaybackConfig` 继续有效，旧安装目录默认文件保留并迁移副本 | 复用 `desktop_playback.parse`；下次启动会话读取；默认保存不修改安装 INI |
| `backend` | 现有后端 home 下 `config.json` | 现有 `version`、`spatialFormat`、`fullTiming`；后端服务重启后加载，FSA 启动可能显式覆盖空间格式 |

读取缺失配置只提供候选默认值，不创建文件、不登记播放配置。第一次成功保存播放 JSON 后才登记 `PlaybackConfig`。候选 DLL 路径采用本工作区当前构建位置，驱动必须选择或填写；校验不打开驱动，也不保证模块文件、设备采样率或缓冲实际可用。

图形界面覆盖渲染后端、源流、设备驱动与采样/缓冲、时钟匹配、预缓冲、排空超时、模块路径、主音量、DSP bypass、12 声道 trim/延迟、limiter/前视、ROAR 半径映射、命名顺序/自定义路由。ROAR 当前模式为 OLR；LIRA 的特殊映射留在后端，不接受 ROAR 的半径选项。已弃用的有限等待/欠载次数字段只在完整 JSON 中兼容保留，不重新提供界面控制。

接线展示修正：校准与路由分区；路由中直接显示完整声道排列及“输出槽 → 声道 → ASIO 设备输出”表，切换标准/DVS/自定义排列时同步预览。界面设备通道从 1 开始，与设备常见标号一致；序列化仍使用原 JSON 的零起始索引，不改变实际映射合同。切换排列保留各槽的物理设备通道配置，校准始终跟随标准声道。

保存只写配置，不自动应用、不重启、不启动 NSp、不打开 ASIO。页面显示保存修订和生效时机；目前没有可靠的“运行配置文件修订”记录，明确显示未知，不用文件新修订假冒当前生效修订。后端状态返回其实际内存配置和会话数据，可供核对。损坏 JSON 以原文返回供修复，不擅自用默认值覆盖。

## HTTP 接口

| 方法与路径 | 作用 |
|---|---|
| `GET /api/web/bootstrap` | 本次 Host 的写入 nonce、只读/配置能力 |
| `GET /api/web/status` | FSA 管理快照、已有后端状态；未知/过期明确返回 |
| `GET /api/web/drivers` | 只读取本机 ASIO 注册项，不加载驱动 |
| `GET /api/web/config/{playback,backend}` | 路径、存在性、SHA-256 修订、JSON、校验结果、生效时机 |
| `PUT /api/web/config/{playback,backend}` | `{revision, config}`，先共享校验，再检查旧修订、原子保存 |

接口不提供文件路径参数、目录浏览、任意配置文件操作、运行控制或控制代理。写入要求 `application/json`、本次 Host 的 `X-NSP-Token`；请求严格检查 Host、Origin 与浏览器跨站标志，不提供 CORS。请求头 8 KiB、请求体 64 KiB，单连接有界超时。只读 nonce 受浏览器同源策略保护；服务只面向当前本机用户环境，未扩展成多用户授权服务。

写入用同目录临时文件、同步及原子替换；Web 写操作串行并持有专用锁，旧修订冲突返回 409。外部编辑器不遵循这个锁时，仍可能在检查之后与替换之间竞争，不能声称对任意外部工具实现跨文件事务。播放 JSON 已写入、INI 登记失败时接口明确失败，文件保留，供修复后重试。
